# CheckWords

Программа в трее Windows. Следит за набором текста и **пищит**, если слово набрано не в той раскладке
(EN / RU / UK). По хоткею **перепечатывает** слово в нужной раскладке и переключает раскладку.

| Действие | Клавиша по умолчанию |
|---|---|
| Исправить последнее слово (повторное нажатие перебирает EN → RU → UK) | `Alt` + `\` (левый или правый Alt) |
| Исправить выделенный текст | `Ctrl` + `Alt` + `\` |
| Включить / выключить | двойной клик по иконке |

Пример: набрали `ghbdtn ` и услышали сигнал. Нажали `Alt+\`, получили `привет `, раскладка стала RU.

`\` — клавиша над Enter (`|` с Shift). Она ничего не печатает с AltGr ни в одной из трёх раскладок,
поэтому перехват не отнимает символов. Тонкости, которые учтены:

- **Правый Alt в украинской раскладке — это AltGr**: Windows добавляет к нему фиктивный левый Ctrl
  (скан-код `0x21D`). Программа отличает его от настоящего Ctrl, поэтому правый Alt + `\` везде
  означает «слово», а `Ctrl` + `Alt` + `\` — «выделение». Набор `ґ` через AltGr не мешается.
- **Отпускание Alt не открывает меню окна**: пока Alt зажат, отправляется «маскирующая» клавиша `VK 0xE8`.
- **Пока модификаторы зажаты, ничего не печатается** (иначе Backspace стал бы Alt+Backspace = «Отменить»).
  Если их не отпустить за 2 секунды, действие отменяется.

## Запуск

```bash
dotnet run --project src/CheckWords
```

Сборка одного exe (нужен установленный .NET 10 Desktop Runtime):

```bash
dotnet publish src/CheckWords -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

Чтобы exe работал без установленного .NET, используйте `--self-contained true` (файл будет около 70 МБ).

## Тесты

```bash
dotnet run --project tests/CheckWords.Tests
```

Тесты используют настоящие раскладки Windows, поэтому должны быть установлены EN, RU и UK.
Флаг `-v` выводит пропущенные слова с их оценками. Флаг `--autostart` проверяет работу с Планировщиком заданий:
создаёт, читает и удаляет временную задачу `CheckWords.SelfTest` без прав администратора.

## Автозапуск

Пункт меню трея **«Запускать при входе в Windows»** знает о двух способах автозапуска и показывает, какой включён:

| Состояние | Текст пункта | Нажатие |
|---|---|---|
| ничего нет | «Запускать при входе в Windows» | спрашивает «с правами администратора?»: **Да** — задача Планировщика (запрос UAC), **Нет** — запись в реестре |
| запись в реестре `HKCU\…\Run` | «… (без прав администратора)» | убирает запись |
| задача «CheckWords» в Планировщике | «… (Планировщик, с правами администратора)» | после подтверждения удаляет задачу (запрос UAC) |

К тексту пункта добавляются пометки: задача отключена; задача запускает другой exe (путь виден в подсказке);
рядом с задачей есть ещё запись в реестре.

Задача с наивысшими правами нужна, чтобы программа работала и в окнах, запущенных от администратора.
Она запускается через 10 секунд после входа, без лимита времени (по умолчанию было бы 72 часа),
работает и от батареи, с обычным приоритетом.

Включать оба способа сразу нельзя: запись в реестре стартует раньше и запускает копию без прав
администратора, а копия из задачи тогда закрывается (одновременно работает только одна).
Поэтому при запуске программа сама убирает лишнюю запись в реестре, если включена задача.

## Как это работает

1. **Перехват.** Глобальный хук `WH_KEYBOARD_LL`. В буфер пишутся *физические клавиши* (VK + Shift + CapsLock),
   а не символы. Поэтому «перевести в другую раскладку» означает прочитать те же клавиши через `ToUnicodeEx`
   с другой раскладкой. Таблицы `q↔й` не нужны.
2. **Детектор** (`src/CheckWords.Core/LayoutDetector.cs`) для каждого слова сравнивает его вид во всех раскладках:
   - по **словарю** из `Data/*.txt`: если слово в текущей раскладке неизвестно, а в другой известно, это ошибка;
   - по **триграммной модели**, обученной на тех же словах: `ghbdtn` для английского невероятно, `привет` для русского нормально;
   - по **знакам внутри слова**: `e;by` (то есть «ужин») сразу подозрительно.
   Проверка идёт в конце слова (пробел, знак препинания), а если включено, то и на середине слова, начиная с 3–4 букв.
3. **Исправление.** Программа отправляет N × Backspace, затем печатает текст через `SendInput` (Unicode)
   и переключает раскладку окна через `WM_INPUTLANGCHANGEREQUEST`.
4. **Сброс буфера** происходит при клике мышью, смене окна, стрелках, Tab, Enter и сочетаниях с Ctrl/Alt/Win,
   то есть всякий раз, когда уже неизвестно, где стоит курсор.

Точность на отложенных тестовых фразах (слова, которых нет в обучающих списках):

| Набрано в | Имелось в виду | Поймано |
|---|---|---|
| RU / UK | EN | 100% |
| EN | RU | 99% |
| EN | UK | 96% |
| RU | UK | 90% |
| UK | RU | 81% |

Ложных срабатываний 0 на 422 правильно набранных словах и на 95 технических терминах и названиях
(`kubectl`, `useEffect`, `Kyiv` и т. п.).

RU↔UK различаются всего несколькими клавишами (ы/і, э/є, ъ/ї, ё/'). Поэтому эта пара самая трудная.
Её улучшают большие словари (см. ниже).

## Настройки

Всё хранится в `%APPDATA%\CheckWords\` (в трее есть пункт «Открыть папку настроек»):

- `settings.json`: хоткеи (`"Alt+Oem5"`, `"Shift+Pause"`, `"Ctrl+Alt+Space"`: имена клавиш из
  `System.Windows.Forms.Keys` или один символ как в EN-раскладке, в JSON `"Alt+\\"`),
  звук (частота и длительность), список программ-исключений.
  После правки нажмите «Перечитать настройки и словари».
- `user-words.txt`: слова, на которые не надо реагировать. Пункт меню «Не предупреждать для «…»» добавляет их сюда.
- `dict\en*.txt`, `dict\ru*.txt`, `dict\uk*.txt`: **дополнительные большие словари**, по одному слову в строке,
  например выгруженные из Hunspell. Они расширяют и словарь, и триграммную модель и заметно улучшают RU↔UK.

По умолчанию программа не работает в RDP (`mstsc.exe`) и в менеджерах паролей.
Через меню можно выключить её в любой текущей программе.

## Ограничения прототипа

- Окна, запущенные **от администратора**, не видны хуку (защита UIPI). Чтобы работать в них, CheckWords
  тоже нужно запускать от администратора: проще всего через автозапуск с правами администратора (см. выше).
- Хук глобальный: `Alt+\` и `Ctrl+Alt+\` перестают доходить до других программ. Если какой-то программе
  они нужны, смените хоткей или добавьте её в исключения.
- `Ctrl+Pause` как хоткей не подойдёт: Windows присылает его как другую клавишу (`Cancel`).
- Исправление выделенного текста работает через буфер обмена: сохраняется и восстанавливается только *текст*
  из буфера, картинки в нём будут потеряны.
- Мёртвые клавиши сбрасывают буфер текущего слова.
- Ввод, сгенерированный другими программами (макросы, экранная клавиатура), игнорируется.
  Переменная окружения `CHECKWORDS_ACCEPT_INJECTED=1` включает его, но только для автотестов.
- Программа ничего не пишет на диск и никуда не отправляет. Буфер держит максимум 256 последних клавиш в памяти.

## Структура

```
src/CheckWords.Core/   логика без UI: раскладки, словари, детектор, буфер набора, конвертер выделения
  Data/*.txt           встроенные словари EN / RU / UK
src/CheckWords/        WinForms-приложение в трее: хуки, SendInput, меню, звук, настройки
tests/CheckWords.Tests консольный набор проверок и отчёт о точности
```
